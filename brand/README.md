# Logo Packio

| Fichier | Usage |
| --- | --- |
| `packio-logo.svg`, `packio-logo.png` | Logo complet, texte foncé, pour fond clair |
| `packio-logo-blanc.svg`, `packio-logo-blanc.png` | Logo complet, texte blanc, pour fond sombre |
| `packio-icone.svg`, `packio-icone-512.png`, `packio-icone-1024.png` | Icône seule (réseaux sociaux, favicon, application) |

- Couleur principale : bleu Packio `#2f4dff`.
- Police du mot « PACKIO » : Geist Bold, lettres espacées (le texte est vectorisé dans les fichiers, aucune police à installer).
- Les PNG ont un fond transparent. Laissez autour du logo un espace libre au moins égal à la moitié de la hauteur de l'icône.

Le logo du site est dessiné dans `src/components/brand/logo.tsx` ; l'icône de l'onglet du navigateur est `src/app/icon.svg`.
